Raspberry Ripple is a light Chrome theme built from layered raspberry pinks: a saturated raspberry frame, a petal-pink toolbar, and a near-white new tab page with a faint pink cast. Deep plum text on the frame and soft plum links keep everything readable, while the white address bar stands apart from the toolbar. Every surface is a flat, single solid color, so the palette stays calm and low-contrast, with the color concentrated in the frame and tab strip. It recolors the window frame, tab strip, toolbar, address bar, and new tab page.
